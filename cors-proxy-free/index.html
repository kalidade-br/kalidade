Endpoint

Uma URL. Um parâmetro. Pronto.

GEThttps://api-web-br.vercel.app/api/proxy.js?url=URL_DESTINO
Substitua URL_DESTINO pela URL completa da API ou recurso que deseja acessar.
💡 Dica: sempre use encodeURIComponent() no JavaScript quando montar a URL dinamicamente.

Exemplos de uso

Copie, cole e adapte ao seu projeto.

JavaScript · Fetch
const target = 'https://api.example.com/data';
const proxy = 'https://api-web-br.vercel.app/api/proxy.js?url=';

fetch(proxy + encodeURIComponent(target))
  .then(res => res.json())
  .then(data => console.log(data))
  .catch(err => console.error(err));
Node.js · Fetch
const target = 'https://api.example.com/data';
const proxy = 'https://api-web-br.vercel.app/api/proxy.js?url=';

const response = await fetch(
  proxy + encodeURIComponent(target)
);

const data = await response.json();
console.log(data);
