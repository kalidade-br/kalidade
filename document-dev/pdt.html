PDT API

Uma única API com três formas de consulta: por CPF, por nome e por SK.

GET
https://api-kalidade.vercel.app/api/pdt.js

Três funções de consulta

Use somente um dos parâmetros por requisição.

?cpf=

Consulta por CPF

Pesquisa uma pessoa utilizando o CPF informado. Conforme os dados disponíveis, a resposta pode trazer informações como nome, município, SK, NIS e outros campos públicos retornados pela API.

EndpointCopiar
https://api-kalidade.vercel.app/api/pdt.js?cpf=SEU_CPF
?nome=

Consulta por nome

Pesquisa pelo nome. A resposta desta função é destinada a retornar o SK, o nome completo e o CPF com parte do número mascarada no formato ***.456.789-**, conforme você definiu.

EndpointCopiar
https://api-kalidade.vercel.app/api/pdt.js?nome=SEU_NOME
?sk=

Consulta por SK

Pesquisa diretamente pelo identificador SK retornado pelo sistema. Informe o SK no parâmetro da requisição.

EndpointCopiar
https://api-kalidade.vercel.app/api/pdt.js?sk=123456

Parâmetros

ParâmetroFunçãoExemploRetorno descrito
cpf Consulta por CPF 07068093868 Dados públicos disponíveis, como município, SK, NIS e outros campos retornados.
nome Consulta por nome NOME COMPLETO SK, nome completo e CPF parcialmente mascarado.
sk Consulta por identificador 123456 Dados associados ao SK retornado pela API.
Importante: envie apenas um parâmetro de consulta por requisição: ?cpf=, ?nome= ou ?sk=.

Formato das respostas

Os campos exatos podem variar conforme a função e os registros encontrados.

CPF

Use esta seção para documentar o JSON efetivamente retornado pela consulta ?cpf=, incluindo município, SK, NIS e demais campos disponíveis.

Nome

A consulta ?nome= deve apresentar o nome completo, o SK e o CPF em formato parcialmente mascarado.

SK

A consulta ?sk= permite localizar o registro diretamente pelo identificador.

Privacidade: esta documentação não exibe CPF completo como exemplo. Quando a consulta por nome retornar CPF, mantenha a máscara aplicada pela API.

CORS

Exemplo de consumo diretamente pelo navegador.

FetchCopiar
async function consultarPDT(params) {
  const query = new URLSearchParams(params);

  const response = await fetch(
    `https://api-kalidade.vercel.app/api/pdt.js?${query}`
  );

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }

  return response.json();
}

// Exemplos:
consultarPDT({ cpf: "SEU_CPF" });
consultarPDT({ nome: "NOME COMPLETO" });
consultarPDT({ sk: "123456" });
