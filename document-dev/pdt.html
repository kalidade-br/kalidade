PDT CPF

Consulte dados públicos de Pessoa Física relacionados ao Portal da Transparência utilizando o CPF.

GET
https://api-kalidade.vercel.app/api/pdt.js?cpf=07068093868

Sobre a API

A PDT CPF realiza uma consulta de Pessoa Física utilizando o CPF como parâmetro.

Quando existem registros públicos correspondentes, a API pode retornar informações como SK, NOME, CPF, RELAÇÕES e UF.

Método

GET

Entrada

CPF

Saída

JSON

Como utilizar

Envie o CPF através do parâmetro cpf.

Endpoint Copiar 
https://api-kalidade.vercel.app/api/pdt.js?cpf=07068093868

Exemplos de código

Integre a API em seus projetos utilizando GET.

JavaScript — Fetch Copiar 
const cpf = "07068093868";

const url =
    `https://api-kalidade.vercel.app/api/pdt.js?cpf=${encodeURIComponent(cpf)}`;

.then(response => {

    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }

    return response.json();

})
.then(data => {

    console.log(data);

})
.catch(error => {

    console.error("Erro:", error);

JavaScript — Async/Await Copiar 
async function consultarCPF(cpf) {

    const url =
        `https://api-kalidade.vercel.app/api/pdt.js?cpf=${encodeURIComponent(cpf)}`;

    const response = await fetch(url);

    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }

    return await response.json();
}

consultarCPF("07068093868")
    .then(data => console.log(data))
    .catch(error => console.error(error));

Parâmetros

Resposta JSON

Exemplo de resposta retornada pela API. 

{
    "SK": "574920115",
    "NOME": "LUIZ INACIO LULA DA SILVA",
    "CPF": "070.680.938-68",
    "RELACOES": "Servidor Público",
    "UF": "SÃO BERNARDO DO CAMPO - SP"
}
SK — identificador retornado pela consulta.
NOME — nome associado ao registro público.
CPF — CPF apresentado no registro.
RELACOES — relação/categoria encontrada, como "Servidor Público".
UF — localização apresentada no registro.

Campos da resposta

Campo Tipo Descrição
SK String Identificador do registro retornado.
NOME String Nome da pessoa encontrada.
CPF String CPF associado ao registro.
RELACOES String Relação pública encontrada para a pessoa.
UF String Localização/UF apresentada no registro.
A resposta depende dos dados públicos disponíveis para o CPF consultado. O Portal da Transparência disponibiliza consultas de Pessoa Física e categorias como servidores/pensionistas e beneficiários de programas sociais. :contentReference[oaicite:1]{index=1}
