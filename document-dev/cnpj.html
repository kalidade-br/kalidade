```
CNPJ API

Consulte informações de CNPJ através de uma requisição HTTP simples e receba os dados em formato JSON.

GET
https://api-kalidade.vercel.app/api/cnpj.js?cnpj=58478444848444
```
```

Sobre a API

Endpoint para consulta de CNPJ utilizando o parâmetro cnpj.

Método

GET

Formato

JSON

Parâmetro

cnpj

```
```

Como utilizar

Substitua o valor de cnpj pelo CNPJ desejado.

Endpoint Copiar
``` 
https://api-kalidade.vercel.app/api/cnpj.js?cnpj=58478444848444
```
Importante: utilize o CNPJ no parâmetro cnpj. A API utiliza o método HTTP GET.
```
```

Exemplos de código

Integre a CNPJ API em diferentes linguagens.

```
``` JavaScript — Fetch Copiar ``` 
const cnpj = "58478444848444";

fetch(
  `https://api-kalidade.vercel.app/api/cnpj.js?cnpj=${cnpj}`
)
  .then(response => {
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    return response.json();
  })
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.error("Erro:", error);
  });
``` JavaScript — Async/Await Copiar ``` 
async function consultarCNPJ(cnpj) {

  const url =
    `https://api-kalidade.vercel.app/api/cnpj.js?cnpj=${encodeURIComponent(cnpj)}`;

  const response = await fetch(url);

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }

  const data = await response.json();

  console.log(data);

  return data;
}

consultarCNPJ("58478444848444");

```
CORS

Se a aplicação do navegador estiver sujeita a uma restrição de CORS, você pode utilizar um proxy intermediário.

```
``` Fetch + CORS Proxy Copiar ``` 
const api =
  "https://api-kalidade.vercel.app/api/cnpj.js?cnpj=58478444848444";

const proxy =
  "https://corsproxy.io/?url="
  + encodeURIComponent(api);

fetch(proxy)
  .then(response => response.json())
  .then(data => {
    console.log(data);
  })
  .catch(error => {
    console.error(error);
  });
``` cURL + CORS Proxy Copiar ``` 
curl "https://corsproxy.io/?url=https%3A%2F%2Fapi-kalidade.vercel.app%2Fapi%2Fcnpj.js%3Fcnpj%3D58478444848444"
