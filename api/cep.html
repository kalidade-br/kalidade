Como utilizar

Envie o CEP através do parâmetro cep.

Endpoint Copiar 
https://api-web-br.vercel.app/api/cep.js?cep=58300123

Exemplos de código

Integre a KALIDADE API na sua aplicação.

JavaScript — Fetch Copiar 
const cep = "58300123"; fetch( `https://api-web-br.vercel.app/api/cep.js?cep=${cep}` ) .then(response => response.json()) .then(data => { console.log(data); }) .catch(error => { console.error(error); });
cURL Copiar 
curl "https://api-web-br.vercel.app/api/cep.js?cep=58300123"
Node.js Copiar 
const cep = "58300123"; async function consultarCEP() { const url = `https://api-web-br.vercel.app/api/cep.js?cep=${cep}`; const response = await fetch(url); const data = await response.json(); console.log(data); } consultarCEP();
Python Copiar 
import requests cep = "58300123" url = "https://api-web-br.vercel.app/api/cep.js" response = requests.get( url, params={"cep": cep} ) print(response.json())
PHP Copiar 
<?php $cep = "58300123"; $url = "https://api-web-br.vercel.app/api/cep.js?cep=" . urlencode($cep); $response = file_get_contents($url); echo $response;

CORS

Para aplicações que enfrentarem restrições de CORS, você pode utilizar um proxy intermediário.

JavaScript + CORS Proxy Copiar 
const api = "https://api-web-br.vercel.app/api/cep.js?cep=58300123"; const proxy = "https://corsproxy.io/?url=" + encodeURIComponent(api); fetch(proxy) .then(response => response.json()) .then(data => { console.log(data); });
cURL + CORS Proxy Copiar 
curl "https://corsproxy.io/?url=https%3A%2F%2Fapi-web-br.vercel.app%2Fapi%2Fcep.js%3Fcep%3D58300123"
