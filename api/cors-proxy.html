```
PROXY API

Proxy HTTP da KALIDADE API para encaminhar requisições para uma URL de destino através de um único endpoint.

GET
https://api-web-br.vercel.app/api/proxy.js?url=URL_DESTINO
```
```

Sobre a API

O endpoint recebe uma URL através do parâmetro url e realiza a requisição para o destino informado.

Método

GET

Parâmetro

url

Função

Proxy HTTP

```
```

Como utilizar

Informe a URL de destino no parâmetro url.

Endpoint Copiar
``` 
https://api-web-br.vercel.app/api/proxy.js?url=URL_DESTINO
```
Exemplo Copiar
``` 
https://api-web-br.vercel.app/api/proxy.js?url=https%3A%2F%2Fexample.com
```
```
```

Exemplos de código

Exemplos para integração com diferentes linguagens.

```
``` JavaScript — Fetch Copiar ``` 
const destino = "https://example.com";

const url =
    "https://api-web-br.vercel.app/api/proxy.js?url="
    + encodeURIComponent(destino);

fetch(url)
    .then(response => {
        if (!response.ok) {
            throw new Error(`HTTP ${response.status}`);
        }

        return response.text();
    })
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error("Erro:", error);
    });
``` JavaScript — Async/Await Copiar ``` 
async function proxy(urlDestino) {

    const url =
        "https://api-web-br.vercel.app/api/proxy.js?url="
        + encodeURIComponent(urlDestino);

    const response = await fetch(url);

    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }

    return await response.text();
}

proxy("https://example.com")
    .then(data => console.log(data))
    .catch(error => console.error(error));

```
CORS

O proxy pode ser utilizado como intermediário quando uma aplicação precisa acessar um recurso remoto.

```
``` Fetch Copiar ``` 
const destino =
    "https://example.com";

const proxy =
    "https://api-web-br.vercel.app/api/proxy.js?url="
    + encodeURIComponent(destino);

fetch(proxy)
    .then(response => response.text())
    .then(data => {
        console.log(data);
    });
```
Atenção: utilize o proxy somente com URLs e serviços que você tem autorização para acessar. O comportamento final também depende das políticas e respostas do servidor de destino.
```
