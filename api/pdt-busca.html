PDT BUSCA

Consulte dados públicos relacionados ao Portal da Transparência utilizando um termo de busca.

GET
https://api-web-br.vercel.app/api/pdt-busca.js?busca=joao%20vitor%20da%20silva

Sobre a API

A PDT Busca é uma interface da KALIDADE API para consultas no contexto de dados públicos do Portal da Transparência.

O parâmetro busca aceita um termo de pesquisa. Dependendo da fonte consultada, podem ser utilizados valores como nome, CPF, CNPJ, identificadores ou outros termos disponíveis na pesquisa.

Método

GET

Formato

JSON

Origem

Portal da Transparência

Como utilizar

Envie o termo desejado no parâmetro busca. Sempre utilize encodeURIComponent() quando o valor possuir espaços ou caracteres especiais.

Nome Copiar 
https://api-web-br.vercel.app/api/pdt-busca.js?busca=joao%20vitor%20da%20silva
CPF Copiar 
https://api-web-br.vercel.app/api/pdt-busca.js?busca=12345678909
CNPJ Copiar 
https://api-web-br.vercel.app/api/pdt-busca.js?busca=12345678000199

Exemplos de código

Exemplos prontos para integração.

JavaScript — Fetch Copiar 
const busca = "joao vitor da silva";

const url =
    `https://api-web-br.vercel.app/api/pdt-busca.js?busca=${encodeURIComponent(busca)}`;

fetch(url)
.then(response => {

    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }

    return response.json();

})
.then(data => {

    console.log(data);

})
.catch(error => {

    console.error("Erro:", error);

});
JavaScript — Async/Await Copiar 
async function consultarPDT(busca) {

    const url =
        `https://api-web-br.vercel.app/api/pdt-busca.js?busca=${encodeURIComponent(busca)}`;

    const response = await fetch(url);

    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }

    const data = await response.json();

    console.log(data);

    return data;
}

consultarPDT("joao vitor da silva");

CORS

O endpoint pode ser consumido por aplicações web quando a configuração CORS da API estiver habilitada.

Fetch + CORS Copiar 
const busca = "joao vitor da silva";

const url =
    `https://api-web-br.vercel.app/api/pdt-busca.js?busca=${encodeURIComponent(busca)}`;

fetch(url)
.then(response => response.json())
.then(data => {

    console.log(data);

})
.catch(error => {

    console.error("Erro:", error);

});

Exemplos de pesquisa

O mesmo parâmetro pode receber diferentes tipos de termos de consulta.

Nome

joao vitor da silva

CPF

12345678909

CNPJ

12345678000199

Identificador

Utilize o código disponível na base consultada.

Palavra-chave

Termos relacionados aos dados públicos.

Texto

Qualquer termo compatível com a pesquisa de origem.

Resposta JSON

O endpoint retorna os dados recebidos da consulta em formato JSON. 

{
  "dados": [
    {
      "...": "..."
    }
  ]
}
A estrutura exata da resposta depende dos resultados encontrados pelo termo pesquisado e da resposta disponibilizada pela fonte de dados.

Fonte dos dados

O PDT está relacionado ao Portal da Transparência do Governo Federal. A plataforma disponibiliza APIs e dados abertos para diversas categorias, incluindo pessoas físicas, pessoas jurídicas, servidores, benefícios, sanções, despesas e contratos.

Consulte sempre as condições de uso e a documentação oficial do Portal da Transparência ao desenvolver aplicações que utilizem esses dados.
