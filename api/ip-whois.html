IP API

Consulte informações de localização e rede de um endereço IP através de uma requisição GET.

GET
https://api-web-br.vercel.app/api/ip.js?ip=9.9.9.9

Sobre a API

O endpoint recebe um endereço IP através do parâmetro ip e retorna informações de localização, rede, ISP, ASN e outros dados em JSON.

Método

GET

Formato

JSON

Parâmetro

ip

Como utilizar

Informe o endereço IP através do parâmetro ip.

Endpoint Copiar 
https://api-web-br.vercel.app/api/ip.js?ip=9.9.9.9

Exemplos de código

Exemplos prontos para integração.

JavaScript — Fetch Copiar 
const ip = "9.9.9.9";

fetch(
    `https://api-web-br.vercel.app/api/ip.js?ip=${encodeURIComponent(ip)}`
)
.then(response => {

    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }

    return response.json();

})
.then(data => {

    console.log(data);

})
.catch(error => {

    console.error("Erro:", error);

});
JavaScript — Async/Await Copiar 
async function consultarIP(ip) {

    const url =
        `https://api-web-br.vercel.app/api/ip.js?ip=${encodeURIComponent(ip)}`;

    const response = await fetch(url);

    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }

    const data = await response.json();

    console.log(data);

    return data;
}

consultarIP("9.9.9.9");

Python Copiar 
import requests

ip = "9.9.9.9"

url = "https://api-web-br.vercel.app/api/ip.js"

response = requests.get(
    url,
    params={
        "ip": ip
    }
)

response.raise_for_status()

data = response.json()

print(data)

CORS

Para aplicações web, a requisição pode ser feita diretamente pelo navegador caso o endpoint esteja configurado para aceitar CORS.

Fetch + CORS Copiar 
const url =
    "https://api-web-br.vercel.app/api/ip.js?ip=9.9.9.9";

fetch(url)
.then(response => response.json())
.then(data => {

    console.log(data);

})
.catch(error => {

    console.error("Erro:", error);

});
